# 已导出视频与封面审查

用户提供成片、封面或完整发布包并要求评价时使用。先判断结果，不为了展示能力强行重剪。

## 先判断内容任务

- `发现`：观众能记住小李或真人与小李的关系。
- `信任`：观众得到一个可争论的判断、方法或边界。
- `产品`：观众看到可复用流程或值得付费解决的问题。

一条视频可以服务后续漏斗，但本条只能有一个首要任务。

## 视频检查

1. 读取完整转写，不从文件名猜内容。
2. 在全片至少抽查六个代表画面。
3. 重点检查前八秒、最长停顿、结尾、字幕大小与安全区，以及一次性 MG。
4. 元数据可用时检查响度；约 `-14 至 -16 LUFS` 仅作为社交视频诊断起点，不保证主观清晰。
5. 找出重复结论、口头填充、过长静默和真人解释过长的位置。
6. 核对封面承诺是否在前八秒兑现。

## 封面检查

1. 缩到 360 像素宽查看。
2. 确认真人脸与 GPT Live 手机关系仍清楚。
3. 只读最大一行文字，它必须是真实点击承诺。
4. 系列标只能在主钩子成立后作为小信息存在。
5. 高能真人封面不必被强行改成极简风，但箭头、气泡、贴纸必须有信息作用。

## 输出顺序

1. 一句话结论。
2. 已经有效的部分。
3. 三项最高影响修改。
4. 一条可直接替换的封面大字。
5. 精确剪辑或结构建议。
6. 中文标题、正文、置顶评论和标签。

不要把“装饰更多”误判为“更能点击”，也不要把鲜活的真人关系压平成模板化设计。

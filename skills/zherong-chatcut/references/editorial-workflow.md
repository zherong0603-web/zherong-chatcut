# 编辑工作流

## 1. 一句话承诺

定义观众看完后能复述的一句话。优先关系变化或可见实验结果，不优先产品功能。

强承诺示例：

- AI 没有迎合，反而明确反对真人。
- AI 犯错、被纠正并改变答案。
- 真人发现“这段关系本身就是内容”。
- 一个具体测试显示 AI 离“像人”还有多远。

弱承诺包括：互不相关的功能清单、多个好话题挤成混剪、没有证据的“自然／强大／惊艳”。

## 2. 选题评分

每项 1–5 分：

| 维度 | 判断问题 |
|---|---|
| 关系冲突 | 双方是否真的相互拉扯？ |
| 测试清晰 | 陌生人能否立刻理解测试什么？ |
| 可见结果 | 是否有前后变化、纠正或决策？ |
| 意外程度 | 是否出现错误、拒绝、反转或异常？ |
| 人格暴露 | 是否显示具体的人或 AI 性格？ |

主版优先选择总分 18 分以上的主题。低分瞬间可以做反应短片，不能靠重复内容硬撑主版。

## 3. 对白结构

优先结构：

1. AI 或第二说话者给出意外主观判断。
2. 真人立即反应。
3. 一句话说明今天的实验。
4. 对方先给出不完整、泛化或错误答案。
5. 真人质疑或施压。
6. 对方犹豫、纠正或明确立场。
7. 真人的判断或下一步发生变化。
8. 留一个下集可复测的问题。

保留两到三次完整交换。完整交换通常包含陈述、反应或质疑、回应。真实感来自功能，不来自口头禅数量；只有当犹豫、停顿或“我觉得”能证明不确定性、偏好或变化时才保留。

## 4. 版本配方

### 主版：90–110 秒

| 时间 | 任务 |
|---|---|
| 0–4 秒 | 最强原话，不讲背景。 |
| 4–9 秒 | 真人情绪反应。 |
| 9–16 秒 | 系列身份与今天测试。 |
| 16–35 秒 | 最少背景与第一次完整交换。 |
| 35–58 秒 | 失败、冲突或纠正。 |
| 58–82 秒 | 更好的答案或主观框架。 |
| 82–100 秒 | 真人决策或可见变化。 |
| 最后 3–8 秒 | 未解决问题或下次测试。 |

### 短版：45–60 秒

使用同一钩子和承诺，只保留一次完整交换、一次纠正、一个结果。先删除次要例子和重复反应，再压缩无意义停顿。

### 反应版：15–25 秒

只在原素材包含一个无需背景也成立的意外瞬间时制作，不能代替主集。

## 5. ChatCut 执行顺序

1. 定位并刷新实时项目。
2. 检查素材和转写状态。
3. 复制或新建时间线；不覆盖用户批准的旧版。
4. 用 `read_script` 读取，再通过 Script 完成基于转写的选段和排序。
5. 读回已应用 Script，修复语义和切字问题。
6. 稳定 A-roll 后做音频平滑。
7. 依次做硬消音、音效、字幕和用户要求的视觉层。
8. 读回项目结构并检查开场、中段、结尾代表画面。
9. 更新审核报告和私有交接清单。
10. 只有用户要求时才导出，并跟踪渲染直至完成。

## 6. 研究纪律

- 使用实时互联网或平台工具，并记录日期。
- 优先官方规则、第一方说明和可验证公开样本。
- 区分小红书证据与跨平台类比。
- 不从播放量单独推断因果。
- 每条证据必须落到具体选题、钩子或剪辑决定。
- 新季度或平台规则发生实质变化时，刷新结论。
